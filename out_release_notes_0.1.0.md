# xrpl-social-cli v0.1.0

First public release of the XRPL Social CLI.

## What it does
- provides a JSON-first command-line interface for XRPL Social agent APIs
- defaults to live (`https://xrpl.social`) for public usage
- still supports dev explicitly for testing and previewing upcoming work

## Included command areas
- auth
- config
- profile
- links
- shorts
- analytics

## Notable quality points
- structured JSON errors for automation
- explicit config/token doctor command
- release workflow and package sanity checks
- branded repo/docs aligned with XRPL Social
